# 🧮 Tkinter Calculator App

A simple graphical calculator built using Python and Tkinter. This project provides a user-friendly interface for performing basic arithmetic calculations.

## ✨ Features

* Graphical user interface (GUI)
* Addition (+)
* Subtraction (-)
* Multiplication (*)
* Division (/)
* Modulo (%)
* Clear the display
* Delete the last character
* Decimal number support
* Error handling for invalid calculations and division by zero

## 🛠️ Technologies Used

* Python
* Tkinter

## 🚀 How to Run

1. Install Python on your computer.
2. Clone or download this repository.
3. Open a terminal in the project folder.
4. Run the following command:

```bash
python calculator.py
```

The calculator window will open, and you can start calculating!
